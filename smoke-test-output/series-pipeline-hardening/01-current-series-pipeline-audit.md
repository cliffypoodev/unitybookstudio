## Critical Findings Summary

> [!CAUTION]
> The following five findings represent systemic failures in the series generation pipeline. Items 1 and 2 are **critical bugs** that completely prevent series data from reaching the prose LLM during generation.

1. **`buildSeriesContinuityBlock` called with wrong arguments → empty output → series bible NEVER reaches prose LLM during drafting.**  
   `getSeriesContinuity` in `sceneWriter.js` (L1760) calls `buildSeriesContinuityBlock(project)` but the function signature in `seriesBible.js` (L226) expects `(seriesBible, seriesNumber)`. The project object is truthy so the guard passes, but all field accesses (`deaths_and_losses`, `resolved_threads`, `power_shifts`, etc.) return `undefined`, producing an empty string.

2. **`buildVolumeContractBlock` is dead code → entry/exit contracts never constrain generation.**  
   The function is fully implemented in `volumeBible.js` (L186–228) but is never imported or called by any module in the generation pipeline. Volume contracts exist only as display data in the UI.

3. **Polish and export pipelines have zero series awareness.**  
   Four polish modules (`llmProsePolisher.js`, `postDraftCleanup.js`, `finalProofread.js`, `proseQuality.js`) and three export modules (`ExportTab.jsx`, `exportSafetyGate.js`, `buildBookHtml.js`) contain no references to series bibles, volume bibles, or continuity data.

4. **Series data reaches the LLM only indirectly through foundation fields populated at sequel creation time.**  
   `characters_md`, `world_md`, `canon_md`, `voice_md`, and `mystery_md` are set once when a sequel project is created (Dashboard L200 or `buildSeriesSeedConcept`). They are never refreshed if the series bible is updated. This is the **only** working path for series context to reach the LLM.

5. **No post-generation validation checks for series continuity violations.**  
   `manuscriptSafetyGate.js` catches process leaks and contamination. `exportSafetyGate.js` blocks on dialogue issues, slop density, and reference integrity. Neither checks for series-level contradictions (dead characters reappearing, resolved threads reopened, world-rule violations, timeline inconsistencies).
