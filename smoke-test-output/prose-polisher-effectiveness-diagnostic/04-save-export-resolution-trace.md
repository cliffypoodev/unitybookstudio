## Trace: "Was was it a failure…" (Chapter 6, Line ~303)

### Full context from v5.docx:
> `…"Why did she disappear? Was was it a failure, or was it something deeper?"…`

| Location | Contains bad text? | Notes |
|----------|--------------------|-------|
| **Pre-polish chapter content** | ✅ Yes | LLM-generated duplicate auxiliary |
| **Step 3: runPunctuationCleanup** | ✅ Still present | Duplicate word detector (`/\b(\w{2,})\s+(\1)\b/gi`) skips "Was was" due to case-sensitive backreference |
| **All other steps** | ✅ Still present | No step handles this |
| **Polish output** | ✅ Written | Saved with error |
| **Export** | ✅ Present | |

### Why the existing duplicate word detector misses it:

```javascript
// punctuationPolish.js:174
f.content = f.content.replace(
  /\b(\w{2,})\s+(\1)\b/gi,
  (match, word1, word2) => {
    if (SKIP_DOUBLES.has(word1.toLowerCase())) return match;
    punctFixed++;
    return word1;
  }
);
```

The regex backreference `\1` is **case-sensitive** in JavaScript, even with the `/i` flag. The `/i` flag only affects character class matching and literal characters, not backreferences. So `Was was` (capital W, lowercase w) does not match `(\w{2,})\s+(\1)` because `\1` requires exact same text as capture group 1.

## Content Field Persistence Path

After `handleManuscriptPolish()` completes, the save at L4463 writes:

```javascript
// Simplified save flow
chapter.__polishedContent = polishedText;  // in-memory
await prepareChapterContent(polishedText, chapter, project);  // → content_md or content_md_url
await chapter.save();
```

All three content resolution sources now contain the error:
1. `__polishedContent` (RAM) — error present
2. `content_md` (DB inline) — error present  
3. `content_md_url` (GitHub) — error present

Export calls `resolveChapterContent()` which returns the first non-empty source. Since all sources contain the error, export always gets bad text.

## Key Finding: No Post-Polish Gate

```
DRAFT (LLM) → [grammar error generated]
     ↓
POLISH (regex) → [no grammar checker, error passes through]
     ↓
SAVE → [error persisted to all content fields]
     ↓
EXPORT → [error exported to DOCX]
```

**Missing piece:** A post-polish quality gate between "POLISH" and "SAVE" that would catch malformed grammar, quote issues, and excessive slop BEFORE saving.
